# TeamMindscape

מערכת לניהול משימות עובדים, שפותחה במסגרת פרויקט גמר בקורס הנדסאי תוכנה.  
המערכת מאפשרת למנהלים ולעובדים לנהל משימות, לעקוב אחר סטטוסי ביצוע, ולשפר את תהליכי העבודה בארגון.

---

## 🧩 תכונות עיקריות

- ניהול משימות לפי משתמשים
- מעקב אחר סטטוסי משימות (פתוחה, בתהליך, הושלמה)
- ממשק משתמש אינטואיטיבי
- תקשורת בין צד לקוח לשרת באמצעות API

---

## 🛠️ טכנולוגיות

- **Frontend**: React, CSS
- **Backend**: Node.js, Express  
- **ניהול גרסאות**: Git

---

## 🚀 הוראות הרצה

1. היכנס לתיקיית השרת:
   ```bash
   cd server
   npm install
   nodemon app.js
   ```

2. בחלון טרמינל נוסף, היכנס לתיקיית הלקוח:
   ```bash
   cd client
   npm install
   npm start
   ```

## 🔒 תנאי שימוש ופרטיות

- פרויקט זה נוצר במסגרת **פרויקט סיום בקורס הנדסאים**.
- השימוש בקוד ובמערכת מיועד ל**שימוש אישי ופרטי בלבד**.
- **אסור** להשתמש בקוד זה לצרכים מסחריים, עסקיים, או להגשה כחלק מכל עבודה, פרויקט או קורס אקדמי אחר.
- כל שימוש שאינו אישי – נעשה **על אחריות המשתמש בלבד**.
- היוצר **אינו אחראי** לכל נזק ישיר או עקיף שייגרם כתוצאה מהשימוש בקוד.
- אין כל התחייבות לתמיכה, עדכונים או תיקונים.
- השימוש בקוד מהווה הסכמה לתנאים אלה.
